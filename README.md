# Gantha PDF

PDF generation plugin for Gantha ebook builder.

## Installation

Add the following dependency to your `package.json`:

```json
"dependencies": {
  "gantha-pdf": "https://github.com/saturngod/gantha-pdf.git"
}
```

## Configuration

1. Copy `book.toml` from this repository to your project's root directory.
2. Copy `cover.png` to your project's root directory (or update `book.toml` to point to your own cover image).

To customize PDF generation, edit `book.toml`.
